# 四订阅用量面板

安装地址：

```text
https://raw.githubusercontent.com/Abinthur/Surge-for-personal-use/main/modules/subscription-panels.sgmodule
```

在 Surge 的“模块”中选择“从 URL 安装”，粘贴地址并启用。在模块参数中填写：

| 参数 | 内容 |
| --- | --- |
| `xlink_url` | Xlink 的完整 HTTPS 订阅链接 |
| `shandian1_url` | 闪电账号 1 的完整 HTTPS 订阅链接 |
| `shandian2_url` | 闪电账号 2 的完整 HTTPS 订阅链接 |
| `youtu_url` | 悠兔的完整 HTTPS 订阅链接 |
| 四个对应的 `*_account` | 可选，邮箱或自定义账号名称；留空只显示机场名称 |

使用原始订阅地址，不要填写登录页或第三方订阅转换地址。链接中的 `?`、`&`、`=` 原样保留。账号名称不要包含 `&`、双引号或换行。若暂不配置某个账号，对应面板会提示填写链接。

无需机场账号密码、MITM 或证书，也不修改节点、策略组和分流规则。不依赖其他电脑或服务常驻。

## 查看与刷新

- iPhone / iPad：在 Surge 的策略选择页查看四张信息面板。
- Mac：在 Surge 菜单栏的 Panels / 信息面板子菜单查看。
- 点击面板刷新按钮立即查询；打开相关界面时，距离上次刷新超过 1800 秒会触发自动查询，并非后台每半小时固定运行。
- 需使用支持信息面板及模块参数的 Surge 版本，并具备对应功能授权。
- 后续更新模块；若脚本仍为旧版本，可在 Surge 中更新对应的远程脚本资源。

## 字段口径

- 用量来自机场的 `subscription-userinfo` 响应头：已用为上传量与下载量之和，剩余为总额度减已用；以 1024³ 字节换算显示为 GB，与部分后台的十进制显示可能不同。
- 到期时间来自响应头的 `expire`；未返回或返回 0 时显示“暂未提供”，不推定永久有效。
- 到期日、更新时间均按北京时间显示。剩余天数按当前时刻向上取整。
- “更新”指本设备最后一次成功取得用量的时间，不是节点列表更新时间。
- 悠兔额外读取原始订阅中的“距离下次重置剩余”信息；只有机场明确提供时才显示。其余账号未取得可靠重置字段时显示“暂未获取”，不根据到期日推算。
- 用量请求失败时保留上次成功数据，以错误状态明确提示；不会显示为零流量。悠兔重置字段读取失败不影响本次成功取得的用量。

## 隐私与故障处理

仓库只保存通用代码和空参数。订阅链接直接用于设备向对应机场查询；脚本不向第三方转换服务发送链接，不记录链接、机场返回正文或错误原文。缓存只保存用量、日期等展示字段，不保存订阅链接和节点正文。

订阅链接本身具有访问权限。安装参数、配置导出和备份中可能含有链接，请勿公开或把填写后的模块提交到仓库。各设备需要分别检查参数和启用状态。

脚本使用 HTTPS 并验证服务器证书；不自动跟随重定向，避免带凭据的链接意外发往其他地址。如果显示 HTTP 30x，请从机场后台取得当前订阅地址再更新参数。如果显示网络或 TLS 错误，请检查设备网络、链接有效性及机场证书，不要通过关闭证书校验解决。

Xlink 使用 Surge 客户端标识、闪电使用 Clash 客户端标识读取响应头；悠兔会自动请求 Clash 格式取得用量，并请求原始格式取得重置倒计时，用户不用手动转换链接。
